Agents de code

Assistants qui écrivent, modifient et déboguent le code, dans le terminal ou dans l'éditeur.

Aider

https://github.com/Aider-AI/aider

Pair programming dans le terminal, avec intégration Git.

Claude Code

https://code.claude.com/docs/en/overview

Assistant de code agentique pour le terminal.

Cline

https://github.com/cline/cline

Agent de code pour l'IDE, le terminal et le bureau.

Cursor

https://www.cursor.com/

Éditeur de code et agent pour l'implémentation et le débogage.

Gemini CLI

https://github.com/google-gemini/gemini-cli

Agent de code open source pour le terminal.

GitHub Copilot

https://github.com/features/copilot

Assistance au code et workflows d'agents dans GitHub et les IDE.

Goose

https://github.com/aaif-goose/goose

Agent local extensible, avec outils MCP.

Kiro

https://kiro.dev

Agent de code d'AWS avec spécifications et tests.

OpenAI Codex CLI

https://openai.com/codex/

Agent de code d'OpenAI qui tourne localement dans le terminal.

Pi

https://github.com/earendil-works/pi

Agent de code extensible pour le terminal.

https://bolt.new/

Lovable

https://lovable.dev/

Génération d'applications full-stack avec Supabase.

Onlook

https://www.onlook.com/

Édition visuelle des interfaces en parallèle du code.

Replit

https://replit.com/

Création d'applications avec Replit Agent.

v0

https://v0.app/

Génération d'interfaces UI et React par Vercel.
